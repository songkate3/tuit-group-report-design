그룹수업 리포트 디자인 가이드

학부모가 밤에 휴대폰으로 읽는 리포트예요. 총평으로 오늘을 먼저 알려 주고, 아이의 말은 자세히 보기에서 크게 보여줘요.

1. 구성 · 헤더 + 6개의 장

모바일과 PC는 같은 순서예요. PC도 두 단으로 나누지 않고 가운데 760px 한 단으로 이어져요.

헤더레벨 · 친구 아바타(“친구 N명과 함께한 수업”) · 리포트 제목 · 날짜 · 교재 · 튜터
1오늘 {이름}는오늘의 총평 → 수업에서 보인 모습(✦ 2개) → 튜터의 코멘트(사진 + 노트)
2오늘 배운 내용교재 카드(표지 · 제목 · 한 줄 소개 · 두 문장 이야기) + 이런 활동을 했어요 → {이름}의 수업 참여도
3{이름}의 말하기 자세히 보기오늘의 말하기 하이라이트(크게 + 대화 + 다시듣기) → 이런 문장도 혼자서 말했어요 → 오늘 배운 단어와 문장
4친구들과 함께한 말하기같은 질문에 이렇게 답했어요 → 친구와 함께 완성한 활동*
5이렇게 말하면 더 좋아요이렇게 말해 봐요* → 우리 반이 함께 헷갈린 것* → 튜터와 함께 연습한 발음
6집에서 한 문장 복습하기코랄 카드 한 장: 물어볼 질문 + 번역 · 수업에서 한 답 · 부모 안내
데이터가 없는 카드* 표시 카드는 해당 내용이 있을 때만 보여줘요. 없으면 카드째 숨기고 장 번호는 그대로 이어요.
튜터 노트 미등록서비스에서는 카드를 숨겨요(프롬프트 v1.8). 보드의 “튜터 노트가 아직 등록되지 않았어요.”는 자리 표시예요.
다시듣기 버튼STT 확인 전에는 회색(불투명도 .55)으로 두고 누를 수 없어요.
더 보기‘오늘 배운 단어와 문장’은 4개까지 보이고 나머지는 “+ N개 더 보기”로 접어요.
문장 틀 빈칸영어 문장 틀의 빈칸은 “...”로 써요. (예: I can see a/an ... It is ...)

8. PC에서 달라지는 것

  • 가운데 760px 한 단. 두 단으로 나누지 않아요. 상단 바 없이 헤더부터 시작해요.
  • 헤더의 날짜 · 교재 · 튜터는 가로 한 줄(모바일은 세로 3줄).
  • 교재 카드: 표지 132px + 오른쪽에 제목·이야기·활동 리스트(모바일은 표지 72px + 제목만 옆, 본문·활동은 아래 전체 폭).
  • 활동 리스트: 표지 오른쪽 칸에 촘촘한 줄(위아래 5px, 구분선 없음)로 두고, 모바일과 같은 숫자 배지 + ›를 써요.
  • 수업 참여도: 말한 구간 막대 아래 지표 4개를 2×2 칸으로.
  • 혼자 말한 문장의 재생 버튼, 표현 배지는 오른쪽에 붙여요(모바일은 각각 아래 · 위).
  • 크기는 3번 표의 PC 값, 여백은 5번 표의 PC 값을 써요.
